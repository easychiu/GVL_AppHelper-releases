# GVL 航海助手 使用說明

《大航海之路》的自動化小幫手：跑流行、自動跑商、多開輪流跑、陸戰刷鑽戒、航行操帆。

> 遊戲有公告會處罰外掛，使用請自行評估。建議用銀幣小號跑。

---

## 一、安裝（第一次）

1. **開開發者選項**：設定裡連點「版本號」（小米是「OS 版本」）7 次。到開發者選項打開：
   - **USB 偵錯**
   - **無線偵錯**（手機要連 Wi-Fi）
   - 小米另外要開 **USB 偵錯（安全性設定）**，不然點不動畫面
2. **裝 App**：到 [Releases 頁](https://github.com/easychiu/GVL_AppHelper-releases/releases) 下載最新的 `GVLHelper-vN.apk` 安裝（會問是否允許未知來源，按允許）。
3. **裝 Shizuku**（Google Play 或 GitHub：RikkaApps/Shizuku）。打開 Shizuku →「透過無線偵錯啟動」→ 照畫面用配對碼配對 → 按「啟動」，顯示「正在執行」就好。
4. **打開 GVL 航海助手，在主畫面「必要權限檢查」**：
   - **Shizuku**：按「授權」→ 允許
   - **無障礙服務**：按「用 Shizuku 開啟」（失敗才按「前往開啟」自己到系統設定打開）
   - **懸浮窗權限**：按「前往授權」→ 打開「顯示懸浮窗」
5. **背景設定**（不然 bot 會被系統關掉）：設定 → 應用程式 → GVL 航海助手 → 省電策略選「無限制」、允許自動啟動。
6. **遊戲設定**：關掉遊戲的「省電模式」（畫面變暗會認不出東西）。

> 手機重開機或換 Wi-Fi 後 Shizuku 會停，要回 Shizuku 再按一次「啟動」，再把 bot 停掉重開。
> 沒有 Shizuku 也能用無障礙跑，但比較慢；多開類的方案一定要 Shizuku。

## 二、日常操作

1. 主畫面按「🚀 啟動航海懸浮窗」，切到遊戲。
2. 點懸浮球 ⛵ 展開面板 →「選擇運行方案」挑一個 → 依方案勾好選項 →「▶ 啟動運行」。
3. 面板下方「即時執行日誌」會寫 bot 正在做什麼、為什麼停。
4. 「⏸ 暫停」暫時不點；「⏹ 停止運行」結束；「隱藏」把面板收回懸浮球。

bot 跑的時候不要碰遊戲畫面；要自己操作就先暫停。

## 三、各方案

### 自動跑流行
空船先拖航到流行港，量每個採購港的航程挑最近的去買，再回流行港賣。
- **跑第 1／2／3 個流行**：選要跑哪一個流行商品。
- **拖航去買，航行去賣**：取消勾選就全程自己航行。
- 同一輪會記住買賣港，不用每輪重量。
- 港名後面有「!」（要先投資）的港會跳過。

### 自動跑商
啟動時打開買入清單看 1★～4★ 採購書，在**有勾的星**裡挑最多的那一星跑，跑完賣到該海域最高價的港。
- **每一星跑什麼、賣哪個海域**：在 App 主畫面「🛒 自動跑商：每一星跑什麼」設定。紅色星＝特產。
  預設：1★ 水銀劑 → 東地中海、2★ 威士忌 → 西地中海、3★ 大馬士革劍 → 西地中海、4★ 鑽石 → 北海。
- **賣到自家港口（國家任務）**：勾了只賣給自己國家的港。
- 選的海域沒人收時，會自動換一個有賣港的海域。
- 買貨用「批量」。

### 多開跑流行／多帳號跑商
本體和 vivo「應用分身」的帳號輪流跑：一個在航行時切去操作另一個。
- 只支援 vivo 的應用分身，**一定要開 Shizuku**。
- 兩個帳號都先登入好、停在城裡。
- 某個帳號出問題會先跳過，2 分鐘後再試；遊戲畫面凍結時日誌會提示重開該帳號的遊戲。

### 陸戰刷鑽戒
一進場開自動（「直達最終層」，只打攔路）走向攔路，小地圖出現攔路就停下看持有物品：有鑽戒才開打，沒有就退出重進。
- 遊戲裡不用先設自定義。
- 「連續冒險」有勾會自動取消。
- 面板上有累計統計（帶鑽戒比例、打贏／打輸），按「重置」歸零。

### 航行操帆／划船
出港後自動點操帆和狀態鈕（通常一顆、最多四顆）。

## 四、更新

App 每 6 小時自動查新版；bot 沒在跑、Shizuku 正常時會自己下載安裝。主畫面也有「更新」鈕可手動更新。
**vivo 會跳「繼續安裝」確認頁，要自己勾選後按一下。**

## 五、常見問題

| 狀況 | 處理 |
|---|---|
| 懸浮窗啟動不了 | 回主畫面看「必要權限檢查」是否都是 🟢 |
| 日誌寫「控制方式：無障礙」但有裝 Shizuku | Shizuku 停了：回 Shizuku 按啟動，再停掉 bot 重開 |
| 多開方案說要先開 Shizuku | 同上 |
| 一直認不出畫面 | 關掉遊戲省電模式；截圖回報 |
| 跑一跑停下 | 截日誌畫面回報，bot 認不出的畫面會存在手機 `Android/data/com.example.gvlhelper/files/` |
